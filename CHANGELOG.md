## [0.1.0] — 2026-05-23

Initial public release. A local-first event-driven multi-agent swarm built on
NATS JetStream, with Kiro CLI providing the LLM reasoning for each agent.

### Added

#### Runtime

- Workspace of five crates: `agora-core` (shared envelope/bus/daemon/ACP),
  `agora` (supervisor + CLI), `agora-agent` (generic config-driven agent
  process), `agora-console` (ratatui TUI), `daemon-telemetry` (JSONL log
  appender).
- NATS JetStream bus (`AGORA_EVENTS` stream) with durable per-agent pull
  consumers, explicit ack on success, NAK with redelivery on handler
  failure, terminal ack on invalid payloads.
- Generic `DaemonRunner<A: Agent>` runtime: one durable consumer per
  declared subscription, fan-in via `mpsc`, single sequential processing
  loop, `Publisher` handle for emitting child events, 5-second heartbeats
  to the `AGORA_AGENT_REGISTRY` KV bucket.
- Two ACP backends: `MockAcpClient` for local testing and `KiroAcpClient`
  (JSON-RPC 2.0 over stdio) for real LLM-driven workflows.
- HS256 JWT actor tokens with hierarchical scope matching, signed with a
  cluster-local secret generated by `agora bootstrap` using
  `getrandom` (cross-platform CSPRNG).

#### Topology + agents

- Declarative agent topology in `agents.local.json` — no Rust changes
  required to add or modify an agent.
- Six built-in agents (product-manager, system-architect, backend-coder,
  frontend-coder, quality-assurance, security-engineer) wired up to
  exercise the canonical idea → design → code → test → repair → pass
  loopback.
- `_topic` override in agent responses so a single subscription can emit
  to different topics depending on the LLM's decision (used by QA for
  `test.passed` vs `test.failed`).
- Topology validation at startup: unique agent names, declared emit
  topics, supported ACP modes, required `kiro_command` for kiro agents,
  consistent `required_scopes` across same-topic subscribers.
- Supervisor restart policy: up to 3 attempts per process before
  escalating to swarm shutdown.

#### Console

- ratatui-based TUI with multi-pane layout (sessions / events / agents
  / detail / composer).
- Live event tail color-coded by topic family with auto-scroll and
  manual scroll-back.
- Live agent registry pulled from `agent.registry.heartbeat`.
- Session naming via `session.named` events — broadcasts to all consoles
  and replays from JetStream on next startup.
- Commands: `!help`, `!new [name]`, `!rename [name]`, `!agents`,
  `!status <agent>`, `!history <agent>`, `!copy`, `!editor`, `!page`,
  `!reset`, `!clear`, `!exit` / `!quit`.
- Per-agent conversation history (`!history <agent>`) showing events
  received, prompts sent to ACP, responses received, and events
  published — all interleaved by timestamp.
- Direct messaging via `@agent <msg>` with `/steer` and `/queue`
  variants; auto-complete agent names from heartbeats with Tab.
- Multi-line input via `Shift+Enter`, `Alt+Enter`, or `Ctrl+J`.
- `!editor` opens `$EDITOR` for composing long inputs; `!page` opens
  the command output panel in `$PAGER` for long history dumps.
- Clipboard copy via `arboard` (macOS / Linux / Windows).
- Mouse-wheel and `PgUp` / `PgDn` scroll the output panel.

#### CLI

- `agora run <config>` — boot NATS, telemetry appender, and every
  configured agent.
- `agora submit <idea>` — publish a `workspace.idea.submitted` event.
- `agora sessions` — list known sessions with names + event counts.
- `agora session new/rename` — manage session metadata from headless
  contexts.
- `agora agents` — list currently registered agents and their status.
- `agora status <agent>` — print the agent's manifest plus optional
  per-session activity.
- `agora history <agent> --session-id <id>` — full conversation
  timeline (same data as the console's `!history`).
- `agora message <agent> <msg>` — send a steering / queue message.
- `agora replay [--session-id <id>]` — dump events from JetStream.
- `agora bootstrap` — mint the signing key.
- `agora doctor` — preflight check for `nats-server`, `kiro-cli`,
  signing key, topology validity, and bus reachability.

#### Project

- MIT license.
- GitHub Actions CI workflow: `cargo fmt --check`, `cargo clippy
  -D warnings`, `cargo build --workspace`, `cargo test --workspace`.
- Unit tests for envelope round-trip, prompt template rendering,
  topology validation, JWT scope matching.
- `scripts/bootstrap.sh` — one-shot build + key mint.
- `scripts/demo.sh` — submits a canned idea, polls for `test.passed`,
  prints the resulting timeline. Doubles as a manual smoke test.
